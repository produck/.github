# Contributing

This is the entry page for contributors to the `produck` organization.

Use this page to find the current authoritative sources. It is intentionally
lightweight and should not be treated as the canonical policy source.

## What this page is for

- Helps new contributors find the current policy documents quickly.
- Provides a stable entry point instead of duplicating policy text.
- Avoids becoming a second source of truth for rules that live elsewhere.

## What this page is not for

- It is not the canonical definition of AI collaboration rules.
- It is not the canonical definition of Node.js, test, or commit-message
  policy.
- It should not be expanded with duplicated policy text when the authoritative
  document already exists.
